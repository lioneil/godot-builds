# godot-builds

This repository builds the Godot 4.7.2 editor for Linux x86_64 with the patches in `patches/` and publishes each patch set as a release tagged `<version>-<hash of the build script and patches>`. The release holds one file, `godot.tar.xz`, with the editor binary `godot` at its top level.

The patches are offered under the MIT licence, which is Godot's own, and are proposed upstream.
